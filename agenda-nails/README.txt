AGENDA NAILS — COMO EXECUTAR

Requisitos:
- Node.js instalado (versão 18 ou superior recomendada)
- Conexão com a internet para carregar as fontes do Google (opcional)

Passos:
1. Extraia o arquivo ZIP.
2. Abra um terminal dentro da pasta agenda-nails.
3. Execute: npm install
4. Execute: npm start
5. Abra http://localhost:3000 no navegador.

O sistema permite cadastrar clientes, criar e cancelar agendamentos e consultar uma galeria de cores.
Os dados são guardados nos arquivos JSON dentro da pasta data/.

Observação:
Esta é uma versão inicial sem login/autenticação. Não a publique na internet com dados reais de clientes sem implementar medidas adicionais de segurança e privacidade.
